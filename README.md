# Claragatchi

!!!WORK IN PROGRESS!!!

05/16/2026

Background:
This is a virtual pet clone that is my personal pet (no pun intended!) project. I've slowly been working on this project since early 2025, when I made a watered-down alpha build using Scratch 3. During the work process, I've incorporated elements that I've been learning in my studies, such as using arrays, signals, areas, collisions, and input mapping. 

Design Tools:
- Godot (game engine)
- Aseprite (pixel assets)
- Garageband (sound/ sfx)
- Procreate (backgrounds, misc. art)
- Scratch 3 (game engine used for prototyping)

Design Process:

During the prototyping stages, while using Scratch, I made a simple virtual pet sim with 3 interactive buttons and 3 meters to track: Fun, Food, and Care. While waiting, the meters would slowly start to tick down, but interacting with the corresponding button would slightly raise its matching meter. If any of the meters hit 0, it would be game over, and the player would need to restart. The prototype was made mostly with assets built into Scratch, other than the character art, which was original. When moving over to Godot, I wanted to design the space to match the character art style, and the buttons were now individual interactables that would increase the individual meters, which were not implemented yet. There are also other events planned, whether they be interactive elements with various interactions or secret interactions hidden in the setting.

What I Learned:

There was a lot of trial and error to this process, and there still is. While gaining the needed skills by working on individual coding class assignments regarding different systems and functions, this project allowed me to see how all of them would meld together in a single project with no outside guidelines or prompts. I personally chose the virtual pet category because I was always a fan of Tamagotchis and the Pokedometer. One of the biggest takeaways from this project has been to pace myself and break the whole project into smaller chunks to knock them out one by one, rather than jumping between various areas and working scatteredly.

Planning Ahead:

Going forward, I want to have each interactable area have a minigame that boosts the meters up by a certain degree, which can vary depending on how well the minigame is played. Otherwise, once all of the core mechanics are implemented, I can start planning for hidden secrets and easter eggs, possibly even a dress-up mechanic.
